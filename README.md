# Formik Bootstrap

Login and register forms built with Formik and Yup, a reusable `FormikControl` input component, auth requests with axios, and a Jalali (Shamsi) date picker.

تمرین فرم ورود و ثبت‌نام با Formik، اعتبارسنجی Yup و تقویم شمسی.

## Stack
React · Formik · Yup · axios · react-multi-date-picker · moment-jalaali · Tailwind CSS

## Run
```bash
npm install
npm run dev
```
